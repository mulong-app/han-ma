# 韓麻 HEADS-UP

韓国・仁川のパラダイスシティで遊べる韓国式麻雀「韓麻（ハンマ）」をもとにした、対CPU・2人打ちのスピード麻雀です。
ブラウザだけで動きます（PCは横画面、スマホは縦画面のレイアウト）。ホーム画面に追加すると、アプリのように起動でき、オフラインでも遊べます。

**▶ 遊ぶ：** https://mulong-app.github.io/han-ma/

## ルール

- 牌は136枚（萬子・筒子・索子 1〜9と字牌）。チーなし、ポン・カンあり
- 役なし。4面子1雀頭／七対子／国士無双なら和了
- フリテンなし。現物でもロンでき、見逃しもOK
- 点数：ロン／ツモ（6/4・7/4・8/4・6/2から選択）＋リーチ2／ドラ・5ドラ・裏ドラ各1、国士無双20（上限20点）
- ドラ表示牌は2枚。萬子・筒子・索子の5はすべてドラ。カンしても新ドラは増えない
- 1人20ツモ（設定で18〜24）で流局（精算なし）
- 点数と同じ枚数のチップが相手から移動
- 局数は開始前に 1 / 4 / 8 / ∞（どちらかが飛ぶまで）から選択
- 持ち時間切れのたびに1チップを供託。次の和了者が総取り（流局なら持ち越し）

初回起動時に遊び方ガイドが表示されます（スキップ可。メニュー →「遊び方」でいつでも再表示）。

## 操作

- **スマホ（縦）**：手牌をなぞる／タップ、または大きな牌を左右にスワイプして選択。大きな牌を真上にスワイプして離すと打牌（設定でタップ打牌・手牌の選択中タップ打牌に変更可）
- **PC**：牌をクリックで打牌。P / Esc で一時停止

## ファイル構成

```
index.html             ゲーム本体（HTML/CSS/JS 1ファイル）
tiles/                 牌画像（m=萬子, p=筒子, s=索子, r=赤5）
icons/                 アプリアイコン
manifest.webmanifest   ホーム画面追加用
sw.js                  オフライン用キャッシュ
```

## クレジット

- 牌画像：ニコニ・コモンズ 素材 nc64263（作者名・利用条件は素材ページを参照）
- ルールの元ネタ：パラダイスシティ カジノ「韓麻」

※ 実在のカジノとは無関係の非公式ファンメイド作品です。賭博目的での利用はできません。

## BGM・効果音
- 効果音はWeb Audioで合成しています（音声ファイルなし）。
- BGM・ジングルは `bgm/` にあります（title / game / start / victory / defeat、AAC 128kbps、-16 LUFS）。
  - title・game はイントロを1回流したあと、曲中のループ区間を繰り返します（区間は index.html の `BGM_TRACKS`）。
  - 音量は効果音より控えめになるよう `BGM_LEVEL` / `JINGLE_LEVEL` で調整しています。
