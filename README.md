# 韓麻 HEADS-UP

韓国・仁川のパラダイスシティで遊べる韓国式麻雀「韓麻（ハンマ）」をもとにした、対CPU・2人打ちのスピード麻雀です。
ブラウザだけで動きます（PCは横画面、スマホは縦画面のレイアウト）。ホーム画面に追加すると、アプリのように起動でき、オフラインでも遊べます。

**▶ 遊ぶ：** https://mulong-app.github.io/han-ma/

## ルール

- 牌は108枚（萬子は1・9のみ）。チーなし、ポン・カンあり
- 役なし。4面子1雀頭／七対子／国士無双なら和了
- フリテンなし。現物でもロンでき、見逃しもOK
- 点数：ロン6／ツモ4／リーチ2／ドラ・5ドラ・裏ドラ各1、国士無双20（上限20点）
- ドラ表示牌は2枚。萬子以外の5はすべてドラ。カンしても新ドラは増えない
- 1人15ツモで流局（精算なし）
- 点数×ベット倍率（×1／×2／×5）のチップが移動。全10局、またはどちらかのチップが0で終了
- 持ち時間切れのたびに1チップを供託。次の和了者が総取り（流局なら持ち越し）

## 必殺技ゲージ

和了・ドラ・リーチ・ロン・放銃でゲージがたまり、局の開始前に必殺技を使えます。

| Lv | ゲージ | 必殺技 |
|---|---|---|
| 1 | 30 | 透視（CPUの手牌3枚が見える）／配牌やり直し |
| 2 | 60 | ドラ招来（配牌にドラか5が3枚以上）／選択ツモ（3回、2枚から選ぶ） |
| 3 | 100 | 国士トリガー／七対子トリガー（ベット×1固定） |

## 操作

- **PC**：牌をクリックで打牌。P / Esc で一時停止
- **スマホ（縦）**：スライドバーか牌タップで選んで、黄色い「打牌」ボタン（ドラッグで移動可）。左右の三角で1つずつ移動

## 演出連携

ゲーム中のイベントは `window` に `hanma:event` として送られます（リーチ、ポン、和了、テンパイ＝画像の先行生成用、など）。
画像生成やBGMの連携は `addEventListener('hanma:event', e => e.detail)` で受け取れます。

## ファイル構成

```
index.html             ゲーム本体（HTML/CSS/JS 1ファイル）
tiles/                 牌画像（m=萬子, p=筒子, s=索子, r=赤5）
icons/                 アプリアイコン
manifest.webmanifest   ホーム画面追加用
sw.js                  オフライン用キャッシュ
```
